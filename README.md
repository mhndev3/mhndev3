## 🌸 About me

Hi, I'm **Mahan** — a developer who enjoys turning practical problems into software. I build Telegram automation, backend workflows, APIs, and full-stack web products. I care about readable code, thoughtful architecture, and being honest about what is shipped versus what is still in progress.

- 🧩 Building web applications, APIs, bots, and automation tools.
- 🛠️ Working mostly with **Python**, **JavaScript / TypeScript**, **Node.js**, and **Next.js**.
- 🗄️ Working with **PostgreSQL**, **SQLite**, **Redis**, and **Prisma**.
- 🐧 Comfortable with Linux-based development and deployment workflows.
- 🌱 Always learning, improving, and shipping.

### 日本語で
