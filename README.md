## Featured Projects

A selection of public repositories. Project descriptions and implementation status are based on their repository documentation.

### 🤖 [VelaVPN Bot](https://github.com/mhndev3/velavpn-bot)

**Persian Telegram sales & provisioning bot**

A Telegram-first VPN sales workflow connecting payment and admin approval with 3x-ui provisioning and configuration delivery.

- Python 3.14 · aiogram 3.29 · SQLite (WAL)
- 3x-ui integration, QR and config-link delivery
- Wallet, referrals, support tickets, and admin tools

### 🛍️ [Taksaz Yaragh](https://github.com/mhndev3/taksaz-yaragh)

**E-commerce platform for industrial hardware & fittings**

A Next.js and TypeScript application using Prisma and PostgreSQL, with a focus on checkout reliability, inventory correctness, and payment integration.

- Next.js 16 · TypeScript 5 · Prisma 6
- PostgreSQL 16 · ZarinPal integration boundary
- Backend flows manually tested; an automated test suite remains on the roadmap
- Current focus: frontend polish, visual QA, and remaining business decisions

### 🧵 [Vedzmani](https://github.com/mhndev3/Vedzmani)

**Modular-monolith fashion e-commerce**

A split frontend/backend architecture, with Django owning business logic and Next.js handling the presentation layer.

- Next.js · TypeScript · Tailwind CSS
- Django · Django REST Framework
- PostgreSQL · Redis · Nginx
- Playwright E2E · GitHub Actions CI
- Production SMS login, online payment, shipping fees, and unpaid-stock release are documented as not implemented yet

### ☕ [Anteiku](https://github.com/mhndev3/Anteiku-cafe)

**Custom software project platform**

A foundation for a platform to accept and manage custom software-development projects, from websites and bots to APIs and automation.

- Next.js · React · TypeScript · Tailwind CSS v4
- Design tokens and UI primitives
- Foundation phase; authentication, database, backend API, dashboards, and full public site are not built yet
