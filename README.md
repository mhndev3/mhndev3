## 🌸 A little about me

I enjoy turning practical problems into software: from Telegram automation and backend workflows to full-stack web products. I care about readable code, thoughtful architecture, and being honest about what is shipped, what is still in progress, and what needs more work.

- 🧩 Building web applications, APIs, bots, and automation tools.
- 🛠️ Working mostly with **Python**, **JavaScript / TypeScript**, **Node.js**, and **Next.js**.
- 🗄️ Exploring practical data layers with **PostgreSQL**, **SQLite**, **MongoDB**, and **Prisma**.
- 🐧 Comfortable working with Linux-based development and deployment workflows.
- 🍵 Always learning, improving, and shipping small steps.
